# 科研工作台 · Research Workbench

在浏览器中管理科研样品、81 格冻存盒、引物和报销凭证的本地工作台。

## 本地运行

需要 Node.js 22.13 或更高版本和 npm。

~~~bash
npm ci
npm run dev
~~~

打开 [本地工作台](http://127.0.0.1:3100)。首次打开是空库。进入「冰箱与冻存盒」新建一个盒，再录入孔位或从「导入与备份」导入现有表格。

如需运行生产构建，使用以下命令。

~~~bash
npm run build
npm start
~~~

## 功能

| 模块 | 用途 |
| --- | --- |
| 材料库与冻存盒 | 管理菌株、种子、cDNA、NRT、RNA、DNA 和 Primer 管。每盒 81 孔，支持盒图与可编辑台账。 |
| 批量查找 | 粘贴名称清单，核对候选匹配和取样位置。确认后的路线按物理孔位去重，可复制或导出 CSV。 |
| Primer 库 | 记录单条序列或 F/R 引物对，查看长度、Tm、来源与质量提示，支持批量导入。 |
| 科研报销夹 | 按笔填写报销人、金额及凭证，支持多张发票、筛选打包和完整 ZIP 备份。 |
| 配方与实验流程 | 保存自定义的 HTTP 或 HTTPS 入口，链接仅存于当前浏览器。 |
| 导入与备份 | 支持工作台 JSON、9×9 盒表、Primer 表及冻存盒 Excel 台账回导。 |

9×9 盒表首行使用数字 1–9，首列使用字母 A–I。Primer 表可使用「名称」和「Sequence」列，也可使用 Forward / Reverse 列。修改本工具导出的冻存盒台账时，请保留盒标识符、孔位和隐藏的回导原始值工作表。回导会预览差异并检查导出后的并发修改。明确清空孔位时，将「是否占用」设为「否」。

## 本机数据与备份

样品、引物、报销记录和附件存放在当前浏览器的 IndexedDB 中。服务默认只监听本机地址。请使用同一个浏览器配置和同一个地址，浏览器会将不同主机名或端口的数据分开保存。

在「导入与备份」下载工作台 JSON，在「科研报销夹」通过「备份全部」保存报销 ZIP。迁移到新地址或更换浏览器时，可分别恢复这两份备份。备份和导出可能包含真实记录，请将它们保存在仓库目录之外。

## 验证

~~~bash
npm run verify
~~~

验证依次运行 ESLint、TypeScript、生产构建和自动测试。测试数据为合成记录。请在停止该目录正在运行的生产服务后执行验证，以避免构建覆盖当前页面依赖的资源。
