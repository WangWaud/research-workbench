# 科研工作台 · Research Workbench

科研工作台是一款本地优先的实验室记录工具。输入一个样品名，就能查到它所在的冰箱、架位、冻存盒和孔位。也可以粘贴一组名称核对库存、生成取样清单，同时管理引物、报销凭证和实验资料入口。

## 功能

### 总览与全局搜索

- 总览展示材料条数、冻存管数、冻存盒占用情况、Primer 条数和待处理项。待确认的盒位、待核对的孔位、序列提示和备份提醒可以直接打开。
- 顶部搜索支持材料名、分类地位、浓度、盒标识符、冰箱、架位、坐标 A1–I9、数字孔位 1–81 和 Primer。点击材料结果可直接定位并高亮目标孔位。
- 左侧会显示本机数据的保存状态。手机端可通过底部导航和「更多」访问其他模块。

### 冰箱与冻存盒

- 按「冰箱 → 架位 → 冻存盒 → 孔位」管理实际存放位置。每盒为 9×9 共 81 孔，同时显示 A1–I9 和 1–81 两套编号。
- 盒标识符独立于盒名和架位。移动或重命名冻存盒时，可沿用原盒标识符，例如 FBX-001。
- 可在「盒图」和「Excel 表格」之间切换。盒图用颜色区分材料类型，点击孔位打开详情。表格支持直接编辑、失焦或按 Enter 保存，并用 Tab 连续移动。
- 每支管可记录类型、名称、状态、保存日期、提取日期和备注。菌株可记录分类地位，cDNA、RNA、DNA 与 Primer 管可记录带单位的浓度。
- 状态包括正常、待核对、已取出和已废弃。同一材料的多支管各自保留孔位与状态。

### 材料库与批量查找

材料库支持菌株、种子、cDNA、NRT、RNA、DNA 和 Primer 七类材料。可按名称、类型或状态筛选，展开同名材料的各支管，查看浓度和位置，点击任一位置返回对应盒图。

从 Excel 复制一列材料名，粘贴到「批量查找」。也可用换行、制表符、逗号或分号分隔。先选材料类型，再核对命中等级。

| 命中等级 | 含义 |
| --- | --- |
| 精确匹配 | 输入与库内名称一致。同名同类的多支管会一起列出。 |
| 规范化匹配 | 仅有英文字母大小写或全角、半角差异。 |
| 可能匹配 | 去掉空格、连字符或下划线后相同，等待人工核对。 |
| 多个候选 | 命中多个库内名称或材料类型，等待人工核对。 |
| 未找到 | 当前材料范围内无匹配记录。 |

「按输入顺序」适合逐行核对原始名单。「按取样路线」只收录已匹配、状态正常且位置已确认的管，按冰箱、架位和盒分组，并合并重复命中的同一孔位。复制和 CSV 导出遵循当前筛选与排序。

### Primer 库

- 可记录单条序列或一组 F/R 引物，保存原始名称、靶标、用途、长度、Tm、产物长度、来源和备注。
- 支持重点卡片、Excel 表格和紧凑列表三种视图。可按名称、物种、靶标或用途查找，并复制原始序列。
- 从表格导入时可使用「名称」与「Sequence」列，也支持 Forward / Reverse 列。分行记录只有在能唯一识别同名前缀的一组 F/R 时才自动合并。
- 序列占位符、含空格、标注长度不一致或 F/R 原名相同会生成核对提示。可标记人工核对，修改相关字段后会重新检查。
- 实体引物管的位置在冻存盒记录，序列和实验参数在 Primer 库记录。

### 科研报销夹

- 按笔填写用品、金额、报销人、购买日期和备注，支持「小额」和「发票」两类。小额记录可附支付与购买凭证，发票类记录可给同一笔支付添加多张发票。
- 可按月份、类别、报销状态和关键词筛选。列表会显示材料缺项，可选择当前结果或仅选择材料完整的记录。
- 「生成报销包」按选中的记录生成附件 ZIP 和 Excel 清单。默认使用当前筛选内的勾选项，确认窗口会列出实际笔数和金额。
- 「备份全部」生成含全部记录和附件的完整 ZIP，用于恢复报销夹。

### 配方、实验流程与供应商入口

在「配方与流程」填入自己的 HTTP 或 HTTPS 地址。入口保存在当前浏览器，可用于打开实验室的配方页、流程文档或内部工具。「测序与试剂」集中提供常用供应商的公开入口。

## 本地运行

以下命令在 Node.js 24 下验证。

~~~bash
git clone https://github.com/WangWaud/research-workbench.git
cd research-workbench
npm ci
npm run dev
~~~

打开 [本地工作台](http://127.0.0.1:3100)。进入「冰箱与冻存盒」，新建一个盒并点击孔位录入，也可在「导入与备份」粘贴现有盒表。

运行生产构建时使用以下命令。

~~~bash
npm run build
npm start
~~~

## 表格导入与回导

文件上传支持 .xlsx、.xls、.csv 和 .tsv。

| 场景 | 操作 |
| --- | --- |
| 导入已有冻存盒 | 先选中目标盒。粘贴 9×9 盒表或上传 Excel / CSV，首行为 1–9，首列为 A–I。检查预览后应用。 |
| 导入 Primer 表 | 上传含 Primer 名称与序列的 Excel / CSV。预览新记录、配对和核对提示后应用。 |
| 导出盒台账 | 在冻存盒页导出当前盒，或在「导入与备份」导出全部。工作簿含盒索引、孔位明细、盒图和回导原始值。 |
| 批量修改后回导 | 编辑「孔位明细」或「全部孔位」，保留记录键、盒标识符、孔位及隐藏的「回导原始值」表。上传后核对新增、更新、清空和冲突。 |

工作台会用导出原值判断 Excel 实际修改了哪些字段，并对照当前记录检查冲突。要清空孔位，请将「是否占用」明确设为「否」。9×9 盒表和 Primer 表只会更新相应的录入字段。批量导入等操作可在当前页面撤销一次。

## 本机数据与备份

工作台主数据、报销记录和附件保存在当前浏览器的 IndexedDB。默认服务只监听本机 127.0.0.1:3100。使用同一个浏览器配置和同一个地址可继续访问已有数据。更换浏览器、主机名或端口时，可通过备份迁移。

| 数据 | 备份与恢复 |
| --- | --- |
| 冻存盒、材料、Primer | 在「导入与备份」下载工作台 JSON，在目标浏览器从同一页面恢复。恢复前会校验结构并显示将替换的记录数。 |
| 报销记录及附件 | 在「科研报销夹」点击「备份全部」下载 ZIP，在目标浏览器用「恢复备份」导入。 |
| 自定义配方链接 | 在目标浏览器重新填写链接。 |

批量修改前可先按需下载工作台 JSON 和报销 ZIP。备份可能含真实库存、序列和凭证，请将它们保存在仓库目录之外。并行打开多个标签页时，工作台按记录合并主数据修改。同一条记录冲突会暂停自动保存，可先下载本页草稿，再重新读取已保存的数据。
